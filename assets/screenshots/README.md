# Screenshots
Name files `<project-id>-01.png`, `-02.png`, ... (ids: whiplash, prontos, containercode, intelliapt, anzentix, groundup).
Drop them in this folder, then in `script.js` set that project's `shots` number to the count (optional `alts` array for alt text). Nothing else to edit.
Already included: whiplash-01..06, prontos-01..08, containercode-01..07, intelliapt-01..06, anzentix-01..05, groundup-01..05. AnzenTIX also has a demo video in `assets/videos/`. Use 16:10 or 2:1 PNG/JPG, about 1400px wide.
